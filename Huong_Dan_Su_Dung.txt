2. CƠ CHẾ BẢO VỆ CHỐNG GHI ĐÈ DỮ LIỆU (OVERWRITE PROTECTION):
------------------------------------------------------------------------------
  - Cảnh báo tự động: Khi bấm Nút 1, nếu file `2_DANH_SACH_CAN_KIEM_TRA.xlsx` đã tồn tại và đã có dữ liệu ghi chú của cán bộ, ứng dụng sẽ hiện hộp thoại Cảnh báo xác nhận để tránh mất dữ liệu do bấm nhầm.
  - Tự động sao lưu dự phòng: Trước khi ghi đè bất kỳ file nào (File 1, 2, 3, 4, 5), hệ thống luôn tự động tạo bản sao lưu an toàn vào thư mục:
    `📁 Backup/{tên_file}_backup_YYYYMMDD_HHMMSS.xlsx`
  - Tùy chọn Timestamp: Tích chọn "⏱️ Đặt tên file xuất kèm ngày giờ (Timestamp)" để hệ thống tự động gắn hậu tố thời gian vào tên file (VD: `2_DANH_SACH_CAN_KIEM_TRA_20261003_1430.xlsx`), lưu vết song song không bao giờ trùng lặp.

3. QUY TRÌNH VẬN HÀNH 2 BƯỚC HẰNG NGÀY:
------------------------------------------------------------------------------
* BƯỚC 1: TỔNG HỢP VÀ TÁCH ÁN CẦN KIỂM TRA
  1. Mở ứng dụng (chạy `Chay_Ung_Dung.bat` hoặc giao diện `app_vks.py`).
  2. Nguồn file đơn vị:
     - Bấm "📁 Thư mục..." để quét toàn bộ file trong thư mục.
     - HOẶC bấm "📄 Chọn file...", giữ phím Ctrl/Shift để chọn 1, 2 hoặc nhiều file lẻ.
  3. File Tổng cũ (Tùy chọn nạp nối tiếp thông minh):
     - Nếu đã có sẵn File Tổng cũ (ví dụ 11082026.xlsx): Bấm "🔍 Chọn...".
     - Hệ thống tự động nhận diện đúng Sheet 'DATA', bảo toàn 100% các vụ án sẵn có và các ghi chú cũ, chỉ nạp thêm các vụ án mới.
  4. Bấm nút màu Xanh Dương:
     "⚡ Thực hiện Bước 1: Tổng hợp & Lọc danh sách kiểm tra (>= 16 ngày)"
     - Xuất ra `1_FILE_TONG.xlsx` (22 cột nền vàng, đóng băng J2)
     - Tách ra `2_DANH_SACH_CAN_KIEM_TRA.xlsx` (22 cột nền vàng, án >= 16 ngày và chưa ghi chú, đóng băng J2)

* BƯỚC 2: KIỂM TRA VÀ XUẤT BÁO CÁO LÃNH ĐẠO & DANH SÁCH LỖI GỬI ĐƠN VỊ
  1. Cán bộ mở file `2_DANH_SACH_CAN_KIEM_TRA.xlsx`:
     - Cột NOTE NGÀY KIỂM TRA (Cột 18): Cán bộ tự tay điền ngày kiểm tra (ví dụ: 03/10/2026...).
     - Cột NOTE LÀM GIÀU DỮ LIỆU (Cột 15):
       + Nếu đạt: Điền "ĐÃ ĐÍNH KÈM" hoặc "TẠM ỔN" -> Tính vào SỐ VỤ ĐÃ ĐÍNH KÈM (KHÔNG TÍNH LỖI).
       + Nếu có lỗi/vi phạm: Điền cụ thể lỗi (ví dụ: "chưa đính kèm", "LƯU TÊN FILE DOCUMENT", "chưa đổi tên file", "chậm tiến độ"...) -> Tính vào SỐ VỤ LỖI.
     - Cột GHI CHÚ ĐỂ BÁO TÌNH HÌNH (Cột 20): Ghi chú cụ thể -> KHÔNG bị tính lỗi!
     - Các vụ án chưa kiểm tra: ĐỂ TRỐNG HOÀN TOÀN! Ô trống tuyệt đối KHÔNG bị tính lỗi.
     - Lưu file (Ctrl+S) và đóng Excel.

     "📊 Thực hiện Bước 2: Cập nhật kết quả & Xuất Báo cáo - Danh sách lỗi"
